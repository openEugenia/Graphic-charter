Graphic charter

One ecosystem, one identity.

Conferences, projects and tools share the same logo and the same style; only the brand colour changes.

The logo Components Poster

Getting started

The charter is a CSS file, a Sass API and a logo component. Each project of the ecosystem only chooses its brand colour.

1 · Any page 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@openeugenia/graphic-charter@0.3/dist/openeugenia.min.css">
<script type="module" src="https://cdn.jsdelivr.net/npm/@openeugenia/graphic-charter@0.3/logo/oe-logo.js"></script>

<oe-logo animated></oe-logo>
2 · npm 
npm install @openeugenia/graphic-charter

import "@openeugenia/graphic-charter/css";
import "@openeugenia/graphic-charter/logo";
3 · Brand colour 
:root { --oe-brand: #0f766e; }

/* or a preset */
<html data-brand="violet">

Full reference (tokens, Sass API, logo options, components): README on GitHub.
